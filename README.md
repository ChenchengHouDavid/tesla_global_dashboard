## 一、项目概述

基于特斯拉官方金融产品数据，制作交互式地图看板，包含两个视图：

1. **全球金融视图** — 展示 24 国合作金融机构与金融产品类型
2. **销量总结视图** — 展示 8 区域 × 6 年 Tesla BEV 销量分析

覆盖 **24 个国家/地区**（欧洲 17 国 + 亚太 7 国/地区），**25 家金融机构**，**5 类金融产品**。

## 四、功能特性

### 全球金融视图
- **多点集群**：每个国家按金融机构数量显示多个彩色圆点，按银行/产品类型着色
- **点击交互**：点击国家 → 侧边栏显示详情（金融机构 + 金融产品 + 销量趋势）
- **银行介绍页**：25 家机构中有 24 家有详细介绍（点击标签进入三级页面）
- **未披露机构识别**：灰色圆点代表未公开合作方，hover 显示真实名称，选中后显示完整列表
- **视图切换**：「合作伙伴」/「产品类型」两个视图，切换后圆点颜色与图例自动更新

### 销量总结视图
- **区域柱状图**：2025 年各区域销量对比 + 增长率对比
- **热力图**：8 区域 × 6 年销量热力矩阵
- **趋势折线图**：各区域销量走势 + 增长率走势
- **雷达图**：市场规模 / 增长势头 / 稳定性 / 增长潜力四维评估
- **归因分析**：每个区域的销量驱动因素 + 国家级销量排名

## 五、数据说明

### 金融数据
- **来源**：`data/特斯拉主要金融合作伙伴与金融产品.xlsx`
- **覆盖**：24 国，25 家金融机构，5 类产品
- **数据结构**：硬编码在 HTML 中（`DATA[]` 数组）

### 销量数据
- **来源**：Marklines（`全球10年-25年数据.xlsx` 透视表，Tesla 品牌筛选）
- **覆盖**：46 国，2020-2025 年
- **两套数据**：
  - `SD{}` — 46 国明细（地图高亮 + 点击国家迷你趋势图）
  - `_OD{}` — 8 区域汇总（销量总结视图图表数据源）

## 六、技术架构

### 前端技术栈
| 技术 | 版本 | 用途 |
|------|------|------|
| ECharts | 5.5.0 | 世界地图 + 散点标注 + 迷你趋势图 |
| HTML/CSS/JS | 原生 | 页面结构、自定义渲染（柱状图/折线图/雷达图/热力图） |

### CDN 容灾策略
ECharts 库按优先级加载（自动切换）：
1. `cdn.bootcdn.net` — 国内首选
2. `cdn.staticfile.net` — 国内备选
3. `bytecdntp.com` — 字节跳动 CDN
4. `cdn.jsdelivr.net` — 国际备选

### 地图数据
- **来源**：Natural Earth 110m GeoJSON（177 国）
- **嵌入方式**：直接嵌入 HTML（~819KB），无需外部加载
- **支持缩放/拖拽**：`roam: true`

## 八、修改指南

### 更新金融机构
1. 在 `DATA[]` 数组中更新对应国家的 `p`（合作伙伴）字段
2. 如果需要银行介绍，在 `BANK_INFO{}` 中添加条目

### 更新销量数据
1. 销量数据来自 Marklines 透视表（`全球10年-25年数据.xlsx`）
2. `SD{}` 和 `_OD{}` 中的数据需与透视表保持一致

### 颜色体系
- **合作伙伴视图**：出现 ≥2 次的银行有专属颜色（Santander 红 / Crédit Agricole 蓝 / DNB 青 / NF Fleet 橙），其余归「其他银行」灰色
- **产品视图**：标准贷款蓝 / 经营租赁紫 / 气球贷橙 / 融资租赁绿 / 无抵押贷款粉
- **未披露**：绿色（区别于灰色「其他银行」）

## 九、已知限制

1. **移动端适配**：地图在小屏幕上显示不全（需横屏或缩放）
