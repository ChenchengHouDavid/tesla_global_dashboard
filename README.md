# 特斯拉全球金融合作伙伴与产品地图看板 — 项目交接文档

> 最后更新：2026-06-03 | 作者：zhouzhou | 交接版本：V1.0

---

## 一、项目概述

基于特斯拉官方金融产品数据，制作两张交互式地图看板：

1. **金融合作伙伴地图** — 展示各国合作的金融机构（Santander、CA、DNB 等）
2. **金融产品类型地图** — 展示各国提供的产品类型（标准贷款、经营租赁、气球贷、融资租赁）

覆盖 **24 个国家/地区**，横跨 **欧洲（17国）** 和 **亚太（7国/地区）** 两个大洲。

## 四、技术架构

### 前端技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| ECharts | 5.5.0 | 地图渲染 + 散点标注 |
| HTML/CSS/JS | 原生 | 页面结构和交互 |

### CDN 容灾策略

ECharts 库按优先级从以下 CDN 加载（自动切换）：
1. `cdn.bootcdn.net` — 国内首选
2. `cdn.staticfile.net` — 国内备选
3. `jsdelivr.net` — 国际备选

### 地图数据

- **来源**：ECharts 官方 world.json（Apache ECharts 项目）
- **嵌入方式**：GeoJSON 数据直接嵌入 HTML 文件内（~290KB），无需外部加载
- **国家范围**：已精简为 139 个国家（包含所有目标国家 + 主要周边国家作为地理上下文）
- **坐标精度**：经纬度保留 1 位小数

### 地图布局

- **左侧（46% 宽度）**：欧洲区域，中心 [12°E, 54°N]，缩放 5.5x
- **右侧（42% 宽度）**：亚太区域，中心 [115°E, 18°N]，缩放 4x

### 标注系统

每个国家在地图上以**散点 + 文字标签**形式标注：
- 圆点颜色 = 合作伙伴类型 / 产品类型
- 圆点大小 = 合作伙伴数量
- 标签内容 = 国家名称 + 合作机构/产品名称
- 鼠标悬停显示完整 Tooltip（合作伙伴 + 产品全称含中文释义）

## 五、如何修改/更新

### 更新数据

1. 修改 `data/特斯拉主要金融合作伙伴与金融产品.xlsx`
2. 在 HTML 文件中找到 `var D = [` 数组（约第 100 行），更新对应国家的数据
3. 每条数据格式：
   ```javascript
   {n:"国家名", r:"EU或AP", p:["合作伙伴1","合作伙伴2"], pr:["产品1（中文）","产品2（中文）"], c:[经度,纬度]}
   ```

### 新增国家

1. 在 `D` 数组中添加新条目
2. 如果是欧洲国家，在 `EU_MAP` 对象中添加中文→英文映射
3. 如果是亚太国家，在 `apRegions` 数组中添加 `{name:'英文名',itemStyle:{areaColor:'#1a2058'}}`

### 修改颜色/样式

- 合作伙伴颜色：`pc()` 函数（约第 120 行）
- 产品颜色：`prc()` 函数（约第 130 行）
- 标签样式：`makeData()` 函数中的 `label` 配置
- 地图底色：`makeGeo()` 函数中的 `itemStyle.areaColor`

### 修改 CDN 源

在 HTML 文件顶部的 IIFE 中修改 `cdns` 数组：
```javascript
var cdns=[
  'https://your-cdn.com/echarts.min.js',
  // ...
];
```

## 六、已知问题与优化方向

### 已知问题

1. **圆点缩放「全程跟随」未实现**（合并版 `tesla_dashboard.html`）：
   - 已修复：选中国家后缩放导致的**持久错位**（圆点跑位且停下不恢复）——通过监听 `georoam` 事件、缩放/拖拽停止后防抖 90ms 重画圆点解决（`initMap()` 内）。
   - 仍存在的局限：缩放**进行中**圆点会短暂滞后/跳动，手停 ~90ms 后才精确归位，**非全程丝滑跟随**。
   - 根因：圆点用 ECharts custom series 渲染，与 geo 地图是两个独立图层，`renderItem` 不在 roam 每帧自动重跑。
   - 若要「全程丝滑」：需改用原生 `scatter`/`effectScatter` 系列（引擎内建、逐帧同步），但会重做现有的多点环形排布 / 选中展开 / 灰点 hover 等自定义渲染，改动较大，暂不做。详见 `HANDOFF.md` 第五节。
2. **卢森堡标签拥挤**：卢森堡与比利时、德国距离很近，标签可能重叠
3. **亚太标签对齐**：部分亚太国家标签位置可能需要微调 `position` 参数
4. **移动端适配**：地图在小屏幕上可能显示不全

### 建议优化方向

1. **交互增强**
   - 添加地图缩放/拖拽功能（当前 `roam: false`）
   - 点击国家跳转到详细信息页面
   - 添加筛选器（按合作伙伴类型/产品类型筛选）

2. **数据扩展**
   - 添加特斯拉官网链接（各国金融产品页面）
   - 添加利率、月供等金融参数
   - 添加竞品金融产品对比

3. **视觉优化**
   - 使用 ECharts `labelLayout` 防止标签重叠
   - 添加连接线展示合作伙伴跨国覆盖关系
   - 添加动画效果（数据更新时的过渡动画）

4. **部署优化**
   - 将 ECharts 库本地化（避免 CDN 依赖）
   - 压缩 GeoJSON 数据（当前 290KB，可进一步精简）
   - 添加 PWA 支持（离线可用）
